## Convención

Cada documento de etapa describe:
- **Objetivo** — qué problema resuelve.
- **Qué se implementó** — funcionalidades y archivos clave.
- **Decisiones** — elecciones técnicas y por qué.
- **Estado** — completada / en curso, con lo que quedó afuera.

Estos documentos se mantienen actualizados junto con el código y se commitean al repositorio.
